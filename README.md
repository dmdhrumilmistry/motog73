# motog73: open source ROM, recovery and Linux for the Moto G73 5G

Community project to build custom ROMs, a custom recovery and Linux images for the
**Motorola moto g73 5G** (codename `devonf`, MediaTek Dimensity 930 / MT6855).

This repository contains build configuration, scripts and documentation only.
It does not contain proprietary firmware, signing keys, or personal data.
